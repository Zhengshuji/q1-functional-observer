# Claim 19（`app:zero`）的 Cramer 重推

> 独立数学任务（子 agent `claim19-cramer`），用 `FH = H_A` + Cramer 法则替换论文中失效的 `(HᵀH)⁻¹`。
> 所有随机/结构实例均用 `fractions.Fraction` 精确验证；本节不是 Lean 形式化。

## 1. 问题

论文 Claim `app:zero` 取
`F = H_A (HᵀH)^{-1} Hᵀ`，但 `H ∈ ℚ^{q×k}` 只有 `rank H = ω`；`HᵀH ∈ ℚ^{k×k}` 仅在 `ω = k` 时可逆。
反例：`n=4`，两条 Jordan 链，`C=[1,0,0,0]`，`L₀=[0,0,1,0]`，`r=0` ⇒ `k=2, H=(1,0), ω=1`，`HᵀH=diag(1,0)` 奇异。

## 2. 正确构造

**引理 1（存在可逆 ω×ω 子块）**：存在行集 `I ⊆ [q]`、列集 `J ⊆ [k]`，`|I|=|J|=ω`，使 `H_{I,J}` 可逆。

**引理 2（Cramer 解）**：在 `row H_A ⊆ row H`（(5a)，步骤 1）下，定义
`F⁰_{i,I_a} = det H^{(i,a)}_{I,J} / det H_{I,J}`，其余列为 0，
其中 `H^{(i,a)}_{I,J}` 是 `H_{I,J}` 的**第 a 行**被 `((H_A)_{i,j})_{j∈J}` 替换后的矩阵。则 `F⁰ H = H_A`。

**两个必须强调的细节**（原任务描述有两处错）：
1. 需要**行、列两个**指标集 `I, J`——`H_{I,J}` 才是 `ω×ω`；只取列（`H_{:,J}`）在 `q > ω` 时不是方阵。
2. Cramer 分子是**换行**，不是换列：换列算的是 `H_{I,J}^{-1}hᵀ`（列向量问题），行向量问题 `y H_{I,J} = h` 必须换行。
   400 组随机精确验证：换列版本在 **130** 组给出错误值，换行版本 400 组全对。

**引理 3（解集）**：`{F : FH = H_A} = F⁰ + {Z : ZH = 0}`，仿射维数 `q(q−ω)`；
自由部分应取 `F` 的**列** `I^c`（`F` 的列对应 `H` 的行），不是 `J`。

**推论（(X,G) 规范化）**：取 `X = H_{:,J}`、`B = H_{I,J}^{-1}H_{I,:}`（`H = XB`；若消元把枢轴块归一化为 `H_{I,J}=I_ω` 则 `B = H_{I,:}`），则对每个解 `F` 都有
`G = FX = H_{A,J}`（**精确等式，不是不等式**），故 `G` 不依赖自由部分；正确取法是
`(X,G) = (H_{:,J}, H_{A,J})`，都是 `(H,H_A)` 的列子矩阵。

## 3. 位长

记号：`h(·)` 为条目位长，输入 `A,C,L₀` 的条目位长 `≤ L`，`n ≤ L`，`L ≥ 4`；
`h(H) ≤ 18n²L`、`h(H_A) ≤ 20n²L`（论文 Claim `app:compressed`，沿用）。

| 量 | 论文 | 修正 |
|---|---|---|
| `F` | `H_A(HᵀH)^{-1}Hᵀ`，`ω<k` 时**无定义** | Cramer：`F⁰_{i,I_a}=det H^{(i,a)}_{I,J}/det H_{I,J}` |
| `h(F)` | —（`H_L`：`≤180n⁴L`） | `≤ 41n⁴L` |
| `h(G)` | `≤ 230n⁴L` | `≤ 20n²L`（改用乘积界则 `≤ 60n⁴L`） |
| `τ₀` | `230n⁴L` | `20n²L` |
| `M` | `≤ 4n³` | `≤ 2n³` |
| Bareiss 中间量位长 | `≤ 930n⁷L` | `≤ 42n⁵L`（论文口径）/ `≤ 123n⁶L`（严格清分母） |
| 算术运算数 | `≤ 64n⁹` | `≤ 8n⁹` |
| 总位运算 | `≈5.5×10⁷ n²³L²` | `1.41×10⁴ n¹⁹L²`（论文口径）/ `1.21×10⁵ n²¹L²`（严格） |
| 极大子式系数 | `232n⁵L` | `≤ 22n³L` |
| `ZᵀZ` 条目 | `470n⁵L` | `≤ 47n³L` |

关键点：
- 行列式用 **Hadamard**：`|det M| ≤ ω^{ω/2} 2^{ωb}`，与 Leibniz 的 `ω!2^{ωb}` 只差低阶项，
  最终 `n` 的指数相同；
- 清分母：每一行的公共分母位长 `≤ ω b`，故 `h(det)` 的界为 `ω(ω+1)b + (ω/2)log₂ω + 1`；
- 严格口径下，`eq:R0` 每个标量方程最多含 `2q ≤ 2n` 个系数，清分母后条目位长
  `τ₁ ≤ 20n²L + 40n³L ≤ 61n³L`，于是 `T ≤ 8n⁹(123n⁶L)² ≈ 1.21×10⁵ n²¹L²`——仍严格优于 `n²³L²`。

## 4. 精确验证

- 结构实例 5 组（`ω<k` 与 `ω=k` 都有），逐项验证 `F⁰H = H_A`、`G = FX = H_{A,J}`、`H = XB`、`GB = H_A`；
- 随机代数压力 400 组（`q,k ≤ 5`，`ω<k` 251 组、`ω=k` 149 组）：`F⁰H = H_A` 全部成立；
  换列 Cramer 在 130 组出错；
- 随机真实实例 300 组（`n ≤ 5`，条目 `∈{−1,0,1}`）：其中 163 组满足 `(5a)`，Cramer 的 `F` 全部复现 `FH=H_A`。

## 5. 结论

- **`r = 0` 的多项式时间结论不受影响**，且指数更优；
- 论文需要改的是：`F` 的构造（Cramer，换行）、`τ₀`、`M`、Bareiss 常数、总位运算数；
- 需要补写明的假设：`ω ≥ 1`、`det H_{I,J} ≠ 0` 由精确消元找到、`ω=0` 走步骤 2、
  `(X,G)` 必须取 `(H_{:,J}, H_{A,J})` 而不是任意秩分解；
- `prop:zero` 的定理级主张仍然成立；`cor:time` 的 `min{...}` 形式不受影响。
